# Assets

Drop **web-optimized** images here. Prefer JPEG/WebP under ~500 KB each when possible. Keep originals in `raw/` or `source-media/` locally (those folders are gitignored).

| Folder | Put here |
| --- | --- |
| `brand/` | Logo, wordmark, favicon sources |
| `hero/` | Key art / homepage hero stills |
| `stills/` | Film stills for galleries or sections |
| `cast/` | Cast / crew portraits |
| `leadership/` | Directors / producers / leadership portraits |
| `posters/` | Poster art |
| `press/` | Small web-ready press images only (not full press kits or ZIPs) |

**Do not commit** trailers or large video — use YouTube/Vimeo embeds. Full press packs go off-repo (Drive/Dropbox) and link out.

Suggested naming: `hero-key-art.webp`, `still-01.jpg`, `cast-name.jpg`, `poster-vertical.jpg`.
